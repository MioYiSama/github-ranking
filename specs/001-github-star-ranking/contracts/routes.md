# Contract: Static Routes

## Purpose

Define the visitor-facing static route contract generated by Astro.

## Routes

### `/`

Overall repository ranking.

**Required content**

- Page title identifying the site as GitHub repository star rankings.
- Last successful update time.
- Stale-data indicator when the snapshot is older than 36 hours.
- Linkable navigation to each configured language ranking.
- Ranking table with up to 1000 entries sorted by star count descending and stable tie-breaker.
- Empty or unavailable state if no overall entries are present.

### `/languages/[slug]/`

Language-specific repository ranking.

**Required content**

- Language display name.
- Last successful update time.
- Stale-data indicator when applicable.
- Link back to the overall ranking.
- Linkable navigation to other configured language rankings.
- Ranking table with the fetched entries for the selected language, defaulting to up to 100 entries and configurable up to 1000 entries.
- Empty state if the language has no available entries.

### Unknown Language Route

Unknown language slugs are not generated as static pages. Visitors should reach the nearest static 404 behavior supported by GitHub Pages/Astro.

## Ranking Table Contract

Each repository row must expose:

- Rank
- Repository full name
- Star count
- Primary language when known
- Description when available
- Link to GitHub repository

## Static Generation Contract

- All configured language pages are generated at build time using `getStaticPaths()`.
- No route requires server-side rendering.
- No route requires visitor authentication.
- No route fetches GitHub data in the browser.
